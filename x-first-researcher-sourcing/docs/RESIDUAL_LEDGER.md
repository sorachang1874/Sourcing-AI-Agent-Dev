# Residual Ledger

Every deliberate *no* — an accepted review residual, a deferred contract extension, a rejected
mechanism — is a row here, not a memory. Format and lint rule follow the ai-assisted-engineering
playbook (`templates/RESIDUAL_LEDGER.template.md`); run the check via
`python3 scripts/check_residual_ledger.py` (also covered by `tests.test_residual_ledger`).
